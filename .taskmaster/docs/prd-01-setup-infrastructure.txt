# PRD: Setup Testing Infrastructure for Pi-Controller

## Product Overview
Establish the foundational testing and quality assurance infrastructure for the pi-controller project, including SonarQube integration for code quality analysis and Playwright test framework for end-to-end UI testing.

## Problem Statement
The pi-controller project currently lacks:
1. Automated code quality analysis (SonarQube not configured)
2. Comprehensive end-to-end testing infrastructure (Playwright setup incomplete)
3. CI/CD integration for quality gates and test automation
4. Standardized test fixtures and mock data for consistent testing

## Goals & Success Metrics

### Primary Goals
- Configure SonarQube integration with minimum 80% code coverage requirement
- Set up complete Playwright testing infrastructure with fixtures and mocks
- Integrate both systems into CI/CD pipeline
- Enable parallel test execution for efficient testing

### Success Metrics
- SonarQube successfully scans codebase on every PR
- Quality gates block PRs with critical/blocker issues
- Playwright tests run in < 5 minutes locally
- All tests pass in CI/CD environment
- Mock API endpoints provide consistent test data

## User Stories

### Story 1: SonarQube Integration
**As a** developer
**I want** SonarQube to analyze my code on every commit
**So that** I can identify and fix quality issues before they reach production

**Acceptance Criteria:**
- SonarQube project created and configured
- Authentication credentials securely stored in GitHub secrets
- Quality gates configured with 80% minimum coverage
- Code smells, bugs, and vulnerabilities reported
- GitHub PR checks display SonarQube status
- Scan results visible in SonarQube dashboard

### Story 2: Playwright Test Infrastructure
**As a** QA engineer
**I want** a standardized Playwright testing framework
**So that** I can write consistent, reliable end-to-end tests

**Acceptance Criteria:**
- Playwright configuration file with browser settings
- Test fixtures for authentication, nodes, clusters
- Mock API endpoints for consistent test data
- Helper utilities for common test operations
- Tests run successfully both locally and in CI
- Test reports generated with screenshots on failure

## Technical Requirements

### SonarQube Configuration

#### Files to Create:
1. **`sonar-project.properties`** (project root)
   ```properties
   sonar.projectKey=pi-controller
   sonar.organization=yorkserv
   sonar.sources=internal,pkg,cmd
   sonar.tests=test
   sonar.go.coverage.reportPaths=coverage.out
   sonar.test.inclusions=**/*_test.go
   sonar.exclusions=**/vendor/**,**/web/**
   ```

2. **`.github/workflows/sonarqube.yml`**
   - Trigger on: push to develop, main; pull requests
   - Steps: checkout, setup Go, run tests with coverage, SonarQube scan
   - Use sonarcloud-github-action for scanning
   - Report status back to PR

#### Configuration Requirements:
- Quality Gate: "Sonar way" with custom conditions:
  - Coverage on New Code: >= 80%
  - Duplicated Lines on New Code: <= 3%
  - Maintainability Rating: A or B
  - Reliability Rating: A
  - Security Rating: A
- Configure branch analysis for develop and main
- Enable PR decoration for inline comments

### Playwright Test Infrastructure

#### Files to Create:

1. **`web/kubes-aura/tests/setup/fixtures.ts`**
   ```typescript
   import { test as base } from '@playwright/test';

   export interface TestFixtures {
     authenticatedPage: Page;
     mockNodes: Node[];
     mockClusters: Cluster[];
   }

   export const test = base.extend<TestFixtures>({
     // Fixture implementations
   });
   ```

2. **`web/kubes-aura/tests/setup/test-data.ts`**
   - Mock node data (5+ nodes with various states)
   - Mock cluster data (3+ clusters of different types)
   - Mock GPIO pin configurations
   - Mock system metrics data
   - Mock user credentials for testing

3. **`web/kubes-aura/tests/utils/helpers.ts`**
   - login(page, username, password)
   - navigateTo(page, route)
   - waitForApiResponse(page, endpoint)
   - fillForm(page, formData)
   - assertToast(page, message)

4. **`web/kubes-aura/playwright.config.ts`** (enhanced)
   ```typescript
   export default defineConfig({
     testDir: './tests',
     fullyParallel: true,
     retries: process.env.CI ? 2 : 0,
     workers: process.env.CI ? 2 : undefined,
     reporter: [
       ['html'],
       ['json', { outputFile: 'test-results/results.json' }],
       ['junit', { outputFile: 'test-results/junit.xml' }]
     ],
     use: {
       baseURL: 'http://localhost:8080',
       trace: 'on-first-retry',
       screenshot: 'only-on-failure',
     },
     webServer: {
       command: 'npm run dev',
       port: 8080,
       reuseExistingServer: !process.env.CI,
     },
   });
   ```

5. **`web/kubes-aura/tests/setup/global-setup.ts`**
   - Start mock backend server
   - Seed test database
   - Configure test environment variables

6. **`web/kubes-aura/tests/setup/global-teardown.ts`**
   - Stop mock backend server
   - Clean up test data
   - Generate test report summary

#### Package.json Updates:
```json
{
  "scripts": {
    "test": "playwright test",
    "test:ui": "playwright test --ui",
    "test:headed": "playwright test --headed",
    "test:debug": "playwright test --debug",
    "test:report": "playwright show-report"
  }
}
```

### CI/CD Integration

#### GitHub Actions Workflow: `.github/workflows/playwright.yml`
```yaml
name: Playwright Tests

on:
  push:
    branches: [develop, main]
  pull_request:
    branches: [develop, main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Install dependencies
        working-directory: web/kubes-aura
        run: npm ci
      - name: Install Playwright Browsers
        working-directory: web/kubes-aura
        run: npx playwright install --with-deps
      - name: Run Playwright tests
        working-directory: web/kubes-aura
        run: npm run test
      - name: Upload test results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: playwright-report
          path: web/kubes-aura/playwright-report/
```
