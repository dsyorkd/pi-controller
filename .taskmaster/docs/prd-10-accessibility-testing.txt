# PRD: Accessibility Compliance Testing

## Test Scenarios

### Keyboard Navigation
```typescript
test('should navigate entire form using keyboard', async ({ authenticatedPage }) => {
  await authenticatedPage.goto('/pi-controller/settings');

  // Tab through form fields
  await page.keyboard.press('Tab');
  await expect(page.locator('input[name="hostname"]')).toBeFocused();

  await page.keyboard.press('Tab');
  await expect(page.locator('select[name="timezone"]')).toBeFocused();
});
```

### ARIA Labels
```typescript
test('should have proper ARIA labels on interactive elements', async ({ authenticatedPage }) => {
  await authenticatedPage.goto('/pi-controller');

  const buttons = await page.locator('button').all();
  for (const button of buttons) {
    const ariaLabel = await button.getAttribute('aria-label');
    const text = await button.textContent();
    expect(ariaLabel || text).toBeTruthy();
  }
});
```
