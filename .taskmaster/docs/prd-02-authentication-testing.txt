# PRD: Authentication Flow Testing

## Product Overview
Comprehensive end-to-end testing of the pi-controller authentication system, including login, registration, session management, and security validations using Playwright.

## Problem Statement
The authentication system is critical for security but currently lacks:
1. Automated testing of login/registration flows
2. Validation of session persistence and "Remember Me" functionality
3. Security testing for common vulnerabilities (XSS, CSRF, brute force)
4. Error handling verification for edge cases
5. Session timeout and automatic logout testing

## Goals & Success Metrics

### Primary Goals
- Achieve 100% test coverage of authentication flows
- Validate all security best practices are implemented
- Ensure seamless user experience across login/registration
- Verify session management works correctly

### Success Metrics
- All authentication tests pass consistently (0% flake rate)
- Login flow completes in < 2 seconds
- Registration validation catches all invalid inputs
- Session persistence works across browser restarts
- Security vulnerabilities detected and prevented

## User Stories

### Story 1: Successful Login
**As a** registered user
**I want** to log in with my credentials
**So that** I can access the pi-controller dashboard

**Acceptance Criteria:**
- Login form displays correctly with username and password fields
- Valid credentials redirect to `/pi-controller` dashboard
- "Remember Me" checkbox persists session across browser restarts
- Login success shows welcome message or indicator
- Failed login displays appropriate error message
- Form prevents submission with empty fields

### Story 2: User Registration
**As a** new user
**I want** to create an account
**So that** I can start using pi-controller

**Acceptance Criteria:**
- Registration form validates all required fields
- Password strength requirements enforced
- Email format validated
- Duplicate username/email prevented
- Successful registration redirects to login page
- Clear error messages for validation failures

### Story 3: Session Management
**As a** logged-in user
**I want** my session to persist appropriately
**So that** I don't have to log in repeatedly

**Acceptance Criteria:**
- Session persists across page navigation
- Session persists across browser refresh
- "Remember Me" extends session duration
- Session expires after configured timeout
- Expired session redirects to login page
- Logout clears session completely

### Test Scenarios

#### Scenario 1: Valid Login Flow
```typescript
test('should login successfully with valid credentials', async ({ page }) => {
  // Navigate to login page
  await page.goto('/auth/login');

  // Verify page loaded
  await expect(page).toHaveTitle(/Login/);
  await expect(page.locator('h1')).toContainText('Login');

  // Fill in credentials
  await page.fill('input[name="username"]', mockUsers.validUser.username);
  await page.fill('input[name="password"]', mockUsers.validUser.password);

  // Submit form
  await page.click('button[type="submit"]');

  // Verify redirect to dashboard
  await expect(page).toHaveURL(/\/pi-controller/);

  // Verify user is logged in (check for user menu or indicator)
  await expect(page.locator('[data-testid="user-menu"]')).toBeVisible();
});
```

#### Scenario 2: Invalid Credentials
```typescript
test('should show error for invalid credentials', async ({ page }) => {
  await page.goto('/auth/login');

  await page.fill('input[name="username"]', 'invaliduser');
  await page.fill('input[name="password"]', 'wrongpassword');
  await page.click('button[type="submit"]');

  // Should not redirect
  await expect(page).toHaveURL(/\/auth\/login/);

  // Should show error message
  await expect(page.locator('.error-message')).toBeVisible();
  await expect(page.locator('.error-message')).toContainText(/Invalid credentials/i);

  // Form should remain filled (username) but password cleared
  await expect(page.locator('input[name="username"]')).toHaveValue('invaliduser');
  await expect(page.locator('input[name="password"]')).toHaveValue('');
});
```

#### Scenario 3: Form Validation
```typescript
test('should validate empty form fields', async ({ page }) => {
  await page.goto('/auth/login');

  // Try to submit empty form
  await page.click('button[type="submit"]');

  // Should show validation errors
  await expect(page.locator('input[name="username"]:invalid')).toBeVisible();
  await expect(page.locator('input[name="password"]:invalid')).toBeVisible();

  // Should not submit
  await expect(page).toHaveURL(/\/auth\/login/);
});
```

#### Scenario 4: Remember Me Functionality
```typescript
test('should persist session with Remember Me', async ({ page, context }) => {
  await page.goto('/auth/login');

  // Login with Remember Me checked
  await page.fill('input[name="username"]', mockUsers.validUser.username);
  await page.fill('input[name="password"]', mockUsers.validUser.password);
  await page.check('input[name="rememberMe"]');
  await page.click('button[type="submit"]');

  // Verify logged in
  await expect(page).toHaveURL(/\/pi-controller/);

  // Get cookies
  const cookies = await context.cookies();
  const sessionCookie = cookies.find(c => c.name === 'session');

  // Verify session cookie has long expiration
  expect(sessionCookie).toBeDefined();
  expect(sessionCookie!.expires).toBeGreaterThan(Date.now() / 1000 + 86400 * 7); // > 7 days

  // Close and reopen browser
  await page.close();
  const newPage = await context.newPage();

  // Navigate to dashboard - should still be logged in
  await newPage.goto('/pi-controller');
  await expect(newPage.locator('[data-testid="user-menu"]')).toBeVisible();
});
```

#### Scenario 5: Registration with Validation

```typescript
test('should validate password strength', async ({ page }) => {

  await expect(page.locator('.password-error')).toContainText(/at least 8 characters/i);
});
```

#### Scenario 6: Session Timeout
```typescript
test('should expire session after timeout', async ({ page }) => {
  // Login normally (without Remember Me)
  await page.goto('/auth/login');
  await page.fill('input[name="username"]', mockUsers.validUser.username);
  await page.fill('input[name="password"]', mockUsers.validUser.password);
  await page.click('button[type="submit"]');

  await expect(page).toHaveURL(/\/pi-controller/);

  // Fast-forward time (mock server should handle this)
  await page.evaluate(() => {
    localStorage.setItem('sessionExpiry', String(Date.now() - 1000));
  });

  // Try to navigate to a page
  await page.goto('/pi-controller/nodes');

  // Should redirect to login
  await expect(page).toHaveURL(/\/auth\/login/);
  await expect(page.locator('.session-expired-message')).toBeVisible();
});
```

#### Scenario 7: Logout
```typescript
test('should logout and clear session', async ({ page, context }) => {
  // Login first
  await page.goto('/auth/login');
  await page.fill('input[name="username"]', mockUsers.validUser.username);
  await page.fill('input[name="password"]', mockUsers.validUser.password);
  await page.click('button[type="submit"]');

  await expect(page).toHaveURL(/\/pi-controller/);

  // Click logout
  await page.click('[data-testid="user-menu"]');
  await page.click('button:has-text("Logout")');

  // Should redirect to login
  await expect(page).toHaveURL(/\/auth\/login/);

  // Session cookie should be cleared
  const cookies = await context.cookies();
  const sessionCookie = cookies.find(c => c.name === 'session');
  expect(sessionCookie).toBeUndefined();

  // Trying to access protected route should fail
  await page.goto('/pi-controller');
  await expect(page).toHaveURL(/\/auth\/login/);
});
```

### Security Test Scenarios

#### SQL Injection Prevention
```typescript
test('should prevent SQL injection in login form', async ({ page }) => {
  await page.goto('/auth/login');

  // Attempt SQL injection
  await page.fill('input[name="username"]', "admin' OR '1'='1");
  await page.fill('input[name="password"]', "password' OR '1'='1");
  await page.click('button[type="submit"]');

  // Should not login
  await expect(page).toHaveURL(/\/auth\/login/);
  await expect(page.locator('.error-message')).toBeVisible();
});
```

#### XSS Prevention
```typescript
test('should sanitize XSS attempts', async ({ page }) => {
  await page.goto('/auth/register');

  // Attempt XSS in username
  await page.fill('input[name="username"]', '<script>alert("xss")</script>');
  await page.fill('input[name="email"]', 'test@example.com');
  await page.fill('input[name="password"]', 'SecurePass123!');
  await page.fill('input[name="confirmPassword"]', 'SecurePass123!');
  await page.click('button[type="submit"]');

  // XSS should be sanitized, not executed
  page.on('dialog', dialog => {
    throw new Error('XSS alert was triggered!');
  });

  // Wait to ensure no alert
  await page.waitForTimeout(1000);
});
```
